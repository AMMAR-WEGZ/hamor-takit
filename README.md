# ✈️ منصة وكالة هامور للسفر والسياحة (HAMOOR TRAVEL)

منصة ذكية وشاملة لحجوزات الطيران، البواخر، التأشيرات، وبصات السفر.

## 🌟 المميزات
- **بوابات الطيران الحية المباشرة:**
  - بوابة طيران بدر (Live Zenith PSS)
  - بوابة طيران تاركو الرسمية
- **محرك وكالة هامور المتطور:**
  - تغطية شاملة لجميع مطارات السودان (12 مطار)
  - جميع مطارات الخليج المباشرة (11 مطار)
  - وجهات إفريقيا (9 مطارات)
  - أسعار بالجنيه السوداني ودفع مباشر عبر تطبيق بنكك (حساب هامور: `2198031`)
- **لوحة تحكم موظفي العمليات:**
  - ربط فوري مع نظام TT Interactive
  - دردشة حية وفورية مع العميل
  - مدقق مستندات الجوازات والـ KYC
- **بواخر وسياحة بحرية، تأشيرات دخول، وحجوزات بصات.**
